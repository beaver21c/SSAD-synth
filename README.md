# SSAD-synth — 가상 사회보장행정데이터 분석 환경 (작동 시연판)

가상(합성)의 사회보장행정데이터를 대상으로 ① 통계 프로그램(OpenStat Studio)에 자연어 명령 창을 붙인 분석 화면과
② 정책 대시보드를 한 서버에서 여는 구성이다. 언어모형은 Gemini API(이용자 본인 키)를 쓴다.

> 수치는 모두 가상데이터의 집계값이며 실제 현황이 아니다.
> 원 설계는 폐쇄망 안의 로컬 언어모형을 전제로 한다. 이 저장소는 그 구성을 가상데이터에 한해 외부 API로 작동시켜 보는 시연판이다.

## 현재 상태 (2026-11-22)

| 구성 | 상태 |
|---|---|
| 원본(`원본/`: 가상데이터, 분석 함수 ssda 0.7.6, 조립기, 프롬프트, 평가 문항·채점기, 대시보드, 생성 체계) | 포함. 구성 목록은 `원본/MANIFEST.md` |
| 통계 프로그램 + 자연어 명령 창 + 대시보드를 한 서버로 실행 (`app/`) | 기동·화면 표시 확인 |
| 분석 과정(코드 점검 → 격리 실행 → 출력 통제 → 결과 카드·명령 기록) | 기록된 모형 응답을 다시 넣어 가상데이터에서 실제로 돌려 확인 |
| Gemini API 로 하는 실제 질의 | 키를 넣어 확인해야 함(미확인) |
| 자동 시험 (`tests/run_eval.py`) | 키 없이 경로 점검까지 확인. Gemini 로 돌린 결과는 아직 없음 |
| Windows 실행기·삭제(`START.bat`, `UNINSTALL.bat`) | Windows 에서 돌려 보지 못함(미확인) |

## 실행 (내려받아 본인 컴퓨터에서)

1. 저장소 화면의 Code → Download ZIP 으로 내려받아 압축을 푼다(통계 프로그램, 가상데이터, 대시보드가 모두 들어 있음).
2. Windows 는 `START.bat` 더블클릭, macOS·Linux 는 터미널에서 `./START.sh`.
   - 최초 1회는 Python 패키지를 설치하느라 3~10분 걸린다. Python 3.10 이상이 필요하다.
3. 기본 브라우저에 화면이 열린다: http://127.0.0.1:8500/ (정책 대시보드는 화면의 「정책 대시보드」 또는 /dashboard).

### 삭제

- Windows `UNINSTALL.bat`, macOS·Linux `./UNINSTALL.sh`.
- 1단계: 실행 중인 서버를 끄고, 이 폴더 안에 설치된 실행 환경(`.venv`)과 실행 기록(`workspace_nl`, `openstat/workspace`, `openstat/reports`)을 지운다. 내려받은 직후 상태로 돌아간다.
- 2단계(선택): 폴더 전체를 지운다. 통계 프로그램·대시보드·가상데이터가 모두 제거된다.
- 이 프로그램은 폴더 밖에 파일을 설치하지 않는다. 컴퓨터에 깔린 Python 은 건드리지 않는다.

화면의 「API 키」에 Gemini API 키를 넣으면 자연어 명령 창이 켜진다. 키는 서버 메모리에만 보관되고 서버를 끄면 사라진다.
환경 변수 `GEMINI_API_KEY` 로 줄 수도 있다. 키를 파일에 적어 저장소에 올리지 않는다.

## 자동 시험

원본의 독립 검증 문항(188문항, 묶음 A~H)을 Gemini 로 돌리고, 미리 직접 계산해 둔 참값과 화면에 제시된 값을 대조해 채점한다.

```bash
export GEMINI_API_KEY=...                                   # 키는 파일에 적지 않는다
.venv/bin/python tests/run_eval.py --name g1 --sample 3     # 묶음마다 3문항씩 먼저
.venv/bin/python tests/run_eval.py --name g1 --resume       # 한도 초과 등으로 멈추면 이어서
.venv/bin/python tests/run_eval.py --name full              # 전체
```

결과는 `tests/results/<이름>/report.md` 에 묶음별 정답률, 조용한 오답(틀린 값을 그럴듯하게 제시), 정답이 아닌 차례의 질문·코드·오류 단서로 정리된다.

## 자연어 분석의 처리 순서

질문 → 참고 자료 검색(변수 설명 등) → 언어모형이 집계 전용 분석 함수(ssda) 코드 작성 → 실행 전 점검 → 격리 실행 → 출력 통제(최소 관측 수 미달 칸 억제 등) → 결과 카드.
Google 로 나가는 것은 질문, 참고 자료, 출력 통제를 거친 집계 결과이며 개인 단위 자료는 나가지 않는다.

## 유의

- 그림의 한글은 컴퓨터에 깔린 한글 글꼴(맑은 고딕, AppleGothic, 나눔고딕 등)을 쓴다. 한글 글꼴이 없는 Linux 에서는 그림의 한글이 깨질 수 있다.
