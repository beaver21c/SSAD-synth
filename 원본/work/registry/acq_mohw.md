## 3. 전사 방법과 검증 규율

- 추출: `pymupdf` 단어 좌표(`get_text("words")`) → y 클러스터링으로 행 복원 → 열 중심 x에 스냅. 읽기순서 기반 청킹은 결측셀에서 어긋나므로 **좌표 기반만 사용**.
- 통계연보/수급자현황은 **좌·우 두 페이지 펼침(spread)** 구성이며, 페이지 경계 밖(클리핑 영역)에 **보이지 않는 잔여 텍스트**가 남아 있다. 해당 구간은 실제 인쇄면을 이미지로 렌더링해 눈으로 확인한 뒤 x 범위를 잘라냈다(R03 표6·7·8, 표5·15·25 / R05 표5-4-10 마지막 2열).
- **모든 표에 대해 합계 검증을 통과한 것만 CSV로 남겼다.** 검증 축: 계=부분합, 계=남+여, 시도 17개 합=전국, 등급·구간·연령 세부합=소계, 1인당 급여비=금액÷실인원, 시군구 합=시도 합.
- 원문 자체가 내부 불일치인 셀은 **원문 표기 그대로 전사**하고 CSV `비고` 열에 불일치 내용을 명시했다(임의 수정 금지).
- 모든 CSV: UTF-8, 헤더 포함, long(tidy) 형식.
