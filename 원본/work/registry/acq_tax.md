## 1. 접근 경로 규명 (TASIS는 WebSquare SPA)

`https://tasis.nts.go.kr` 는 WebSquare 기반 SPA로 화면 HTML에는 데이터가 없다.
아래 순서로 **내부 JSON 엔드포인트**를 역추적하여 curl/requests 로 직접 조회에 성공했다.

| 단계 | URL | HTTP | 내용 |
|---|---|---|---|
| 1 | `https://tasis.nts.go.kr/` | 200 (1,265B) | `/websquare/websquare.html?w2xPath=/cm/index.xml` 로 JS 리다이렉트 |
| 2 | `https://tasis.nts.go.kr/cm/index.xml` | 200 (20,485B) | w2x 소스. `xf:submission action="/wqAction.do?actionId=..."` 패턴 발견 |
| 3 | `https://tasis.nts.go.kr/cm/header.xml` | 200 (35,147B) | 메뉴 조회 액션 `ATWEPZAA002R01` 확인 |
| 4 | `POST /wqAction.do?actionId=ATWEPZAA002R01` | 200 (41,810B) | 전체 메뉴 트리 → 국세통계 화면 `/ui/ep/e/a/UTWEPEAA01.xml` (MENU_ID=43) |
| 5 | `https://tasis.nts.go.kr/ui/ep/e/a/UTWEPEAA01.xml` | 200 (29,648B) | 통계표 **목록** 액션 `ATWEPEAA001R01` |
| 6 | `https://tasis.nts.go.kr/ui/ep/e/a/UTWEPEAA02.xml` | 200 (104,006B) | 통계표 **데이터** 액션 `ATWEPEAA001R02` |

### 확정된 호출 규약 (재현 가능)

```
목록:  POST https://tasis.nts.go.kr/wqAction.do?actionId=ATWEPEAA001R01
       Content-Type: application/json; charset=UTF-8
       {"dc_search":{"STT_PBL_YR":"2023","STTS_PBL_TYPE_CD":"F,S,Q,U,N,C,1,2,3,4"}}
       → dc_annRptCtlList (762건, 2023년 발행 전체 통계표 카탈로그)

데이터: POST https://tasis.nts.go.kr/wqAction.do?actionId=ATWEPEAA001R02
       {"dc_search":{"STT_PBL_YR":"2023","STTS_MTA_INFR_ID":"<표ID>",
                     "MENU_ID":"43","LANG":"KOR",
                     "STT_ITRF_RTN":[],"STT_ITRF_DCS":[],"STT_ITRF_DCS_RSSM":[]}}
       → dc_result(제목·단위·주석·행열구조) + dc_annRptList(셀 단위 long 레코드)
         + dc_gridHeaderList / dc_headerList / dc_rowTreeview / dc_colTreeview
```

구현: `tools/tasis.py` (TASIS 클래스), 수집 `tools/wf/tax_fetch.py`, 전사 `tools/wf/tax_tidy.py`

**발행연도 2023 = 귀속연도 2022.** 확보한 모든 표에서 응답의 `COL6`(귀속연도) 값이
전부 `2022` 단일값임을 프로그램으로 확인했다(추정 아님).

## 3. 전사 규약 (params/raw/NTS_{표번호}_{설명}.csv)

TASIS 응답의 `dc_annRptList`는 이미 셀 단위 long 레코드(ROW*/COL* 라벨 + VAL1)다. 이를 그대로 tidy CSV로 전사했다.

| 열 | 의미 |
|---|---|
| `STT_NO` | 국세통계 원문 표번호 (예: `4-2-3`) |
| `ATTR_YR` | 귀속연도 (전 레코드 `2022`) |
| `ROW_SECTION` | (해당 표만) 상위 행 섹션 — 아래 §4 참조 |
| `ROW_L1…ROW_Ln` | 행 차원 라벨, **외곽→내부** (`dc_result.rows2` 순서) |
| `COL_L1…COL_Ln` | 열 차원 라벨, **외곽→내부** (`dc_result.cols` 순서) |
| `ROW_ORD` | 원표의 행 표시순번 (1부터, 인쇄본 행 순서와 동일) |
| `VALUE` | 셀 값 (원표 그대로, 반올림·가공 없음) |
| `UNIT` | 원표 단위 (`[단위：백만원]`, `[단위：명]` 등) |

- 라벨의 HTML 들여쓰기 엔티티(`&emsp;`)만 제거했고 그 외 문자열은 원문 그대로다.
- 각주 표기(`[A]`,`[B]`,`[C]` …)는 라벨에 붙은 채로 보존했다. 각주 본문은 원본 JSON의 `dc_result.sttsCmnt`에 있다.
- 원본 응답 JSON을 `params/raw/NTS_{표번호}_{설명}.json` 으로 **전량 보존**했다(제목·단위·각주·행열 트리 포함).

## 4. 행 계층 복원과 검증

- 대부분의 표는 `ROW_L1`(그룹)·`ROW_L2`(세부)가 응답에 명시되어 있어 그대로 사용했다.
- **4-2-3만** `남성`/`여성` 블록이 `결정세액이 있는자`와 `결정세액이 없는자` 아래 두 번 반복되어
  ROW_L1/L2만으로는 모호했다. 표시순번(`ROW_ORD`)과 들여쓰기 깊이로 상위 섹션을 복원해
  `ROW_SECTION` 열을 추가했고, **가산성으로 검증**했다:
  - 총계 20,529,077 = 결정세액 있는자 13,631,685 + 없는자 6,897,392 ✔
  - 있는자 = 남 8,372,606 + 여 5,259,079 ✔ / 없는자 = 남 2,969,737 + 여 3,927,655 ✔
  - 있는자 남성 연령 6구간 합 = 8,372,606 ✔
- 전체 24표에 대해 "소계 = 하위 항목 합" 자동 검사를 수행했다. 불일치는 **백만원 단위 반올림에 따른 ±1~3**
  이거나(예: 3-1-4 결정세액 `25,850` vs 합 `25,853`), **중복 계상이 정상인 항목**(4-3-1 기부금 세액공제:
  정치자금/법정/우리사주/지정 중복 신고 가능)에 국한된다. 구조적 오류는 없다.

## 6. 실패·미확보 기록 (시도기록 요건)

### 6-1. 국세통계연보 EXCEL 일괄본 다운로드 — **실패**
- 목록 조회는 성공: `POST /wqAction.do?actionId=ATWEPGAA001R01` (HTTP 200, 18,606B, 총 37건)
  - `2023년 국세통계연보` EXCEL_FLE_ID=`200000000131510` (등록 2024-01-12)
  - `2022년 국세통계연보` EXCEL_FLE_ID=`200000000121312` (등록 2023-01-02)
- 다운로드 규약 규명: `/cm/index.xml` 의 `scwin.fn_fleDwldByFleId` →
  `POST /keyAction.do` 로 세션 RSA 공개키 수신(2048bit, e=0x10001, HTTP 200 576B) →
  jsbn `RSAKey.encrypt`(PKCS#1 v1.5 type-2) 로 fileId 암호화 → `$p.download("/cfdown.do?actionId=ATWEPZAA009R02", <info><encFileId>…</encFileId></info>, "post")`
- Python으로 동일 절차 재현 후 아래 7가지 변형 시도 — **전부 HTTP 200 / Content-Length: 0 (빈 응답)**

  | 시도 | 결과 |
  |---|---|
  | `POST` form `encFileId=<hex>` (동일 세션) | 200 / 0B |
  | `GET` `?encFileId=<hex>` | 200 / 0B |
  | `POST` JSON `{"encFileId":…}` | 200 / 0B |
  | `POST` JSON `{"info":{"encFileId":…}}` | 200 / 0B |
  | `POST` XML `<info><encFileId>…</encFileId></info>` (± XML 선언) | 200 / 0B |
  | 대문자 hex / 파라미터명 `fileId`·`FLE_ID` | 200 / 0B |
  | 암호화 없이 평문 fileId | 200 / 0B |
- 원인 추정: WebSquare 엔진의 `$p.download` 폼 직렬화 규약(필드명·추가 히든필드) 미확인.
  엔진 번들(`HybridPluginAll_core.js`, `engine/util.js`)은 `/javascript.wq` 로 라우팅되어 개별 취득 불가(404).
- **영향 없음**: 동일 원천의 통계표 데이터를 `ATWEPEAA001R02` JSON으로 전량 확보했고,
  응답에 제목·단위·각주·생산부서까지 포함되어 xlsx 대비 정보 손실이 없다. 재시도 3회 한도 준수 후 중단.
