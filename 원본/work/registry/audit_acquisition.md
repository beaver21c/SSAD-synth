# 확보 산출물 적대적 감사 (audit_acquisition)

- 감사일: 2026-09-02
- 감사 대상: `registry/acq_{employ,kihasa,misc,mohw,nhis,pension,popul,prop,tax,welfare}.md` (10개 에이전트),
  `registry/access_check*.csv` (11개), `params/raw/` 전체 654개 파일 (647MB)
- 감사 방식: **문서의 주장을 믿지 않고 파일·원문에서 재계산**
  1. 파일 실재·크기·매직바이트 전수 확인
  2. acq 문서가 표기한 **행수**를 실제 CSV 파서로 재계산해 대조
  3. 전사 CSV의 **수치를 원본 PDF 해당 페이지 / xlsx 해당 시트 / 원본 JSON**에서 무작위 표본으로 역추적
  4. 라운드넘버·벤포드 이탈 스캔으로 조작 흔적 탐색
  5. HTML 오류페이지를 CSV/PDF로 위장 저장한 사례 탐색
  6. `[1차확인]` 표기 항목의 표번호·페이지 주장 실지 검증

## 2. HTML 오류페이지 위장 저장 — **0건**

- `params/raw` 전 654개 파일의 선두 4KB를 매직바이트로 판정: PDF 49 / ZIP·OOXML 40 / OLE(hwp·xls) 18 / JSON 40 / HTML 3 / TEXT 497 / TSV 1
- **확장자와 실제 형식이 어긋난 파일은 한 건도 없다.**
- 보존된 HTML 3건은 전부 정상 본문 페이지이며, 이를 근거로 만든 CSV의 수치가 HTML 본문에 실재함을 확인:
  - `M01_enara_1561_보훈대상자현황.html` → M01 CSV 84/84
  - `M05_MOTIE_2022에너지바우처_확대_브리핑.html` → 본문 "1인 세대 하절기 **2만 9600원** 동절기 **10만 7600원**…" 실재
  - `M08_KSPO_스포츠강좌이용권_사업소개.html` → 본문 "2022년 01월 월 지원금 인상(8만원 → **8.5만원**), 지원기간 확대(8개월 → **10개월**)" 실재
- 반대로 **실패는 실패로 정직하게 기록**되어 있었다. 예: 문화누리카드 data.go.kr ZIP이 0바이트로 내려온 건, moel 간행물 검색이 1,897B 오류페이지를 반환한 건 등을 "실패"로 명기하고 성공으로 위장하지 않았다.

## 3. 라운드넘버·조작 흔적 스캔 — 없음

- 중앙값: 끝자리 0 비율 **0.108** (이론 0.100), 끝 두 자리 00 비율 **0.011** (이론 0.010) → **정상 분포**
- 끝자리 0 비율이 높게 나온 상위 파일은 전부 구조적 이유가 확인됨:
  - `R15_표12 기준소득월액 구간별` / `R11 본인부담상한액` / `R10_II-3 보수월액구간별` → **구간 경계값·법정 상한액**이 원래 라운드넘버
  - `S4_2022_사업별_법정단가` → **법정 단가**라 라운드넘버가 정상
  - `CODE_sigungu_2022` → 행정코드
- 벤포드 MAD 상위 파일은 전부 **백분율·연도(2016~2022)·가격지수** 등 벤포드가 적용되지 않는 계열

### 7-1. `R_NEMC_2022_응급의료통계연보.pdf` — 감사 지적 4-1 정정

감사는 이 파일을 "출처 기록 없음"으로 판정했으나, **오탐이다.**
확보 주체는 확보 단계(acquire) 에이전트가 아니라 **생성 단계 B32(A5b) 담당 에이전트**이며,
출처는 `params/A5_B32.yaml` 의 `nhi_in_emergency_dur` source 블록에 요건을 모두 갖춰 기록되어 있다:

```yaml
source:
  Rcode: NEMC
  url: https://www.e-gen.or.kr/nemc/statistics_annual_report.do
  file: params/tab/NEMC_2022_응급실이용_성연령별.csv; params/raw/R_NEMC_2022_응급의료통계연보.pdf
  table_no: 2022 응급의료 통계연보(제21호) PART1-2 「3. 2022 전국 응급의료기관 및 응급의료시설
            이용자」 1) 성별·연령별·시도별 응급실 이용
  page: '150'
  extract_date: '2026-09-02'
status: 1차확인
```

- 전사본: `params/tab/NEMC_2022_응급실이용_성연령별.csv` (+ `.meta.json`)
- 용도: `nhi_in_emergency_dur` — 전국 응급실 이용 8,549,733건 / 의료보장 적용인구 52,932,270명
  = 0.1615건/인·년 을 성×연령(10군) 조건부로 배분
- **판정: 사용 가능.** §1.3 시도기록 요건은 params 기록으로 충족된다.
