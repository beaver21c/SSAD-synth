# 블록 간 컬럼 계약 (Column Contract)

파이프라인 `tools/pipeline.py` 는 blocks.json 의 `(order, agent, block)` 순으로
`rules/{agent}_{block}.py` 의 `generate(df, params, ctx)` 를 호출한다.

- `df` : 지금까지 생성된 전체 DataFrame (상위 컬럼 **수정 금지** — 러너가 검사해서 실패시킨다)
- 반환 : 새로 만든 컬럼만 담은 DataFrame (index 는 `df.index` 와 동일)
- `params` : `core.load_params('params/{agent}_{block}.yaml')` 결과 `{'meta':…, 'params':{var: Param}, 'errors':[…]}`
- `ctx` : `{'n_hh': 4200, 'root': …}`

## 실행 순서 (order)

| order | 블록 |
|---|---|
| 1 | B01 B02 |
| 2 | B08 B09 |
| 3 | B07 B10 B11 B27 B31 |
| 4 | B03 B13 B14 B16 B32 |
| 5 | B05 B17 B24 B26 B28 B33 |
| 6 | B15 B18 B19 B25 B29 B30 |
| 7 | B34 |
| 8 | B06 |
| 9 | B04 |

같은 order 안에서는 **에이전트 알파벳순**(A1<A2<A3<A4<A5)으로 실행된다.
즉 order 5 에서는 `B05(A2)` → `B17(A3)` → `B24·B26·B28(A4)` → `B33(A5)` 순.

## 공통 규칙

- 추출대상 밖 = `np.nan` (0 이 아님). 단 코드북이 "무정보 사례 0원 처리"라고 적은 `p_*` 가공 변수는 0.
- `_amt` 계열은 **원 단위 정수**.
- `yn2 ⇒ yn1`, `dur ∈ [1,12]`, `amt > 0 ⇔ yn1=1` (§7 R24) — 반드시 지킬 것.
- 난수는 `core.rng('B##')` 로만 얻는다 (seed = 20220000 + 블록번호). `np.random` 전역 사용 금지.
- `df.head` 는 pandas 메서드다. 가구주 컬럼은 반드시 `df['head']` 로 접근할 것.
