## 2. 법령 원문 확보 (S4) — 농어촌특별세 판정

국가법령정보센터 Open API(`OC=test`)로 원문 열람. 전사본 `params/tab/S4_농어촌특별세_근로소득관련감면_비과세근거.csv`(+`.meta.json`).

| 시도 | URL | HTTP | 결과 |
|---|---|---|---|
| 목록 검색 | `lawSearch.do?OC=test&target=law&type=XML&query=농어촌특별세법` | 200 / 1,843B | 법령ID 001569, 법령일련번호 285905 |
| 본문 | `lawService.do?OC=test&target=law&type=XML&MST=285905` | 200 / 92,775B | 제4조(비과세)·제5조(과세표준과 세율) 전문 |
| 시행령 검색 | `lawSearch.do?…query=농어촌특별세법 시행령` | 200 | 법령일련번호 280835 |
| 시행령 본문 | `lawService.do?…MST=280835` | 200 | 제4조①1호 전문 |
| (실패) | `lawService.do?…&LM=농어촌특별세법` (MST 없이 법령명) | 500 | 법령명만으로는 조회 불가 → MST 필요 |

**결론 [1차확인]**: 농특세법 제5조①1호는 조특법 등에 따른 소득세 감면세액의 20%를 과세표준으로 하는데,
**농특세법 시행령 제4조 제1항 제1호가 「조세특례제한법」 제30조(중소기업 취업자 소득세 감면)를 비과세로 명시 열거**한다.
2022년 근로소득 연말정산 세액감면 1,086,118명 중 1,066,580명(98.2%)이 조특법 §30 감면이고,
나머지(조세조약 1,323명·소득세법상 66명)는 조특법 감면이 아니어서 과세표준이 성립하지 않는다.
→ `labinc_rural_taxamt`·`othinc_ruraltax`·`ybinc_ruraltax` 전량 NaN (규모 미달) 근거.

**한계 [미확인]**: 열람본은 현행(2026.5.12 개정) 통합본이다. 2022년 귀속 시점 연혁본은 대조하지 못했으므로
결론의 지위를 `1차확인`이 아니라 **`논리적추론`** 으로 부여했다.
