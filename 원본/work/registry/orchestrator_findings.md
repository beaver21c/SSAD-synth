## ★1. B24 기초생활보장 — 급여 간 **포함관계 미강제**로 합집합 +40.8% 과다

**개별 급여는 정확하다.** 문제는 합집합이다.

| 급여 | 가중 추정 | 목표(2022-12 수급권자) | 편차 |
|---|---:|---:|---:|
| `nbls_live_yn1` 생계 | 1,469,979 | 1,566,631 | −6.2% |
| `nbls_medi_yn1` 의료 | 1,514,909 | 1,438,045 | +5.3% |
| `nbls_house_yn1` 주거 | 2,256,743 | 2,260,783 | −0.2% |
| `nbls_edu_yn1` 교육 | 310,226 | 303,383 | +2.3% |
| **합집합(수급자)** | **3,322,781** | **2,451,458** (수급권자) / 2,359,228 (일반수급자) | **+35.5%** |

원인 — 선정기준액(2022 기준중위소득 대비)이 급여마다 다르므로 **포함관계가 성립해야 한다**:

```
생계 30%  ⊂  의료 40%  ⊂  주거 46%  ⊂  교육 50%
```

현재 위반: `생계 ⊄ 의료` 208명, `의료 ⊄ 주거` 172명 (표본 9,535 기준).
가중하면 의료⊄주거 위반만으로 약 90만 명이 합집합에 추가된다.

**조치**: B24 에서 **소득인정액(`_recog_inc`) 단일 순위로 4개 급여를 중첩 배정**하라.
급여별로 독립 베르누이를 돌리면 안 된다.
```python
# 소득인정액 오름차순 순위 r (가구 단위)
nbls_edu   = r <= n_edu      # 가장 넓음
nbls_house = r <= n_house
nbls_medi  = r <= n_medi
nbls_live  = r <= n_live     # 가장 좁음
```
각 n_* 는 위 표의 목표 수급권자 수를 가중치로 환산한 표본 인원.
※ 교육급여는 학령기(7~18세) 아동이 있는 가구로 한정되므로 순위 필터 뒤에 조건을 한 번 더 건다.
※ §7 R08 (`nbls_medi ⇔ nhi_type∈{7,8}`) 과 충돌하지 않도록 B31 이 배정한 의료급여 자격을 기준으로 맞출 것.

검증 목표: `targets/S1_totals_verified.yaml` 의
`[S1] 기초생활보장 수급자수 (일반수급자, 시설 제외)` = 2,359,228 (±10%),
`targets/S0_core.yaml` 의 `기초보장급여 수급률 (가구)` = 5.8% (±3%p, 현재 10.94% → +5.14%p 이탈).

## 4. 검증 목표식 버그 (오케스트레이터가 이미 수정함)

- `기초보장급여 수급률 (가구)` · `아동 관련 급여 수급률 (가구)` 가 `head==1` 행만 보고 있었다.
  급여는 개인(아동·수급자)에게 귀속되므로 가구주 행만 보면 0% 가 나온다.
  → `tools/validate.py` 에 `_hh_any()` 파생지표를 추가하고 `kind: expr` 로 교체 완료.
  수정 후 아동 급여는 −1.37%p 로 통과, 기초보장급여는 +5.14%p 로 여전히 이탈(=★1 의 실제 문제).

**교훈**: 목표가 이탈할 때 **목표식 자체의 버그**를 먼저 의심하라. 생성 코드를 고치기 전에
목표식이 재는 것이 정말 그 지표인지 확인할 것.
