## 1. 돌파 경로 (기존 제약의 실제 원인)

기존 기록의 "repository.kihasa.re.kr = 403"은 **오진**이었음.
실제로는 403이 아니라 **JS 챌린지 인터스티셜**(HTTP 200 + `data-token` 쿠키 에코 스크립트).

```
GET https://repository.kihasa.re.kr/... → HTTP 200, <div id="jc-data" data-name="js-challenge" data-token="..." >
→ 응답에서 data-token 추출 → Cookie: js-challenge=<token> 재설정 → 재요청 시 정상 페이지
```
이 우회로 DSpace 5.5 웹 UI 전체(검색·서지·전체목차)를 curl/requests로 열람 가능.
단, `/rest/*`·`/server/api/*` REST 모듈은 미배포(HTTP 404) → **OAI-PMH와 웹 UI만 사용 가능**.

리포지토리의 공개 bitstream은 **표지 JPG뿐**(`/bitstream/201002/43801/2/a2023-18.jpg`),
원문 PDF는 비공개 번들. 그러나 서지의 `dc.identifier.url`이 **PRISM 과제 팝업 URL**을 가리킴:

- R01 → `https://www.prism.go.kr/homepage/asmt/popup/1351000-202200113`
- R02 → `https://www.prism.go.kr/homepage/asmt/popup/1351000-202300013`

PRISM은 React SPA라 curl로 렌더 불가 → `/env.js`와 `main.*.js` 번들을 파싱해 백엔드 API를 역추적:

```
POST https://api.prism.go.kr/prism-be-asmt/v1/entire/info
     {"asmtId":"1351000-202200113"}                       → 파일목록(asmtFileList)
POST https://api.prism.go.kr/prism-be-asmt/v1/progress/download-file
     {"asmtId":..., "fileTypeCd":"D0150004", "fileSn":1,
      "fileWkky":"001", "pdfTrsfYn":"Y"}                  → 원문 PDF 바이너리
```
둘 다 **무인증·무쿠키**로 동작(HTTP 200). `fileTypeCd=D0150004`가 최종보고서, `D0150003`이 요약본.

「통계로 보는 사회보장」은 서지의 `dc.identifier.url`이 mohw 게시판을 가리켜
AGENT_BRIEF에 기록된 `boardDownload.es` 경로로 직접 취득.

### 3.2 가중치 설계 ([1차확인], R02 p87 / 보고서 p69)

```
최종 가중치 = 설계가중치 × 무응답 조정가중치 × 사후층화 가중치
가구: 2단계 레이킹 비(raking ratio) — [1단계] 시군구×가구원수
                                    [2단계] 시군구×가구주 성별×가구주 연령대
가구원: 가구 가중치를 기저로 시군구×가구원 성별×가구원 연령대 사후조정
표본 1가구가 모집단 평균 4.4가구를 대표
```
가구원수 범주 1/2/3/4/5인이상; 가구주 연령대 0-29세부터 5세 구간, 80세 이상.

## 5. 전사 방법과 품질 (재현 가능)

- PyMuPDF `page.find_tables()` 로 페이지별 표 격자 추출 → CSV. 인쇄된 표의 셀 구조를 그대로 보존.
- 병합셀로 행 라벨과 값이 한 셀에 공백결합된 경우, **셀 내 토큰 수가 행 전체에서 일치할 때만**
  결정적으로 행 분해(`unmerge`). 불일치 시 분해하지 않고 원형 유지(값 순서는 인쇄 순서와 동일).
- 다음 4개 표는 병합구조가 심해 **원문 텍스트에서 직접 손전사**:
  `R01_표10-23`, `R02_표11-13`(모두 tidy long), `R02_표10-21`, `R01_표6-13`, `R01_표6-14`.
