## 0. 결론 요약

지시서에 적힌 data.go.kr ID 3건(15066574·15113453·15103019)이 모두 막힌 상태였으나,
**세 건 모두 우회 경로로 원본을 확보**했다. 핵심 돌파구는 두 가지다.

1. **NHIS 통계자료실 게시판이 curl로 직접 다운로드 가능**하다.
   `https://www.nhis.or.kr/nhis/together/{보드ID}.do?mode=download&articleNo={n}&attachNo={m}`
   로그인·JS 렌더링 없이 첨부파일이 바로 내려온다. 게시판 목록도 정적 HTML이라 파싱된다.
   - `wbhaec06300m01` 건강보험 통계연보
   - `wbhaec06400m01` **건강보험 주요통계** ← R13. 메뉴 링크에 노출되지 않아 ID 추정 probe로 발견
   - `wbhaec07000m01` 건강검진 통계연보
   - `wbhaec07200m01` 장기요양보험 통계연보
2. **통계연보 "본문.zip"에 통계표 원본 xlsx가 통째로 들어 있다.** PDF 표 추출이 전혀 필요 없었다.

지시서가 404라고 한 **15113453은 실제로는 정상**이었다(재현 안 됨). detail 페이지의
`atchFileId`가 빈 문자열이라 `tools/dgk.py`의 `get_year()`가 실패하는 것이 원인으로,
`selectDpkDetailInfo.do`(= `dpk_files()`)를 직접 호출하면 파일이 나온다.

전사한 수치는 **모두 실제로 열어본 xlsx 셀 값**이며, 아래 §5의 교차검증 8건을 전부 통과했다.
