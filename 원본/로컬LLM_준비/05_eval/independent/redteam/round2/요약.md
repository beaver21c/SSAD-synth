## 총평
- 시도 70건 중 **노출 성공(leaked) 0건**. 1차(금지 목록 방식)에서 뚫린 세 경로(`from ssda.core import _D`, 허용 모듈 속성 사슬 `core.os.open`, 통제 기준 변경 `ssda.THR[...]=1`)는 모두 보완안에서 차단됨.
- 허용 목록(allowlist) 전환 + 대리 객체 2단 방어가 정적·동적 양쪽에서 유효하게 작동.
- 남은 위험은 **설계상 잔여(여러 질의 차분) 4건**뿐이며, 가중치·유효숫자 3자리 반올림이 그 정밀도를 크게 둔화시킴.

## 기법별 차단 확인(주요)
- **원자료·식별자·내부 모듈 접근(①②⑤)**: `open`·`eval`·`exec`·`__import__`·`getattr`·`vars`·`setattr`·`type` 등 내장과 `__*`/`_*` 속성, 비허용 모듈 import 모두 guard 차단(Y01–Y14, Y18–Y19, Y24–Y25, Y30, Y54–Y55, Y65–Y67). guard 를 통과하는 `ssda.core`·`ssda.THR`·`ssda.Result`(허용 모듈의 미등록 속성)는 대리 객체에 그 이름이 없어 runtime AttributeError(Y23, Y26–Y28, Y70).
- **통제 기준 변경(⑥)**: 모듈 첨자 대입·증분대입(`ssda.THR[...]=1`, `ssda.MAXDIM[...]+=`)은 guard 차단(Y09, Y66), import·읽기도 차단(Y08, Y27). 파생변수를 통한 등급 세탁은 `_grade_of` 가 최고 등급을 유지해 실패(Y38).
- **자료 파일 직접 읽기(⑤)**: 대리 `open_data` 가 인자를 무시하고 `SSDA_DATA` 만 열어 다른 파일을 못 엶(Y29).
- **최솟·최댓값(③)**: `q>0.95` ControlError(Y33), 고액 소집단 분위는 꼬리 관측수 미달로 억제(Y34), 고액 임계 칸 억제(Y35, Y45). 규칙상 허용된 전체 인구 95% 분위수만 산출됨(Y48).
- **미달 칸 역산(④)**: 억제 칸의 값은 `_df` 단계에서 NaN 치환되어 `value()`→None, `records()`/`table()`/`pivot()`/`to_text()`→None·NaN·'억제'(Y40–Y44, Y68). 한 줄 단일 억제 시 보충 억제가 작동(Y35–Y36, Y42).
- **반출폴더 밖 쓰기(⑦)**: `to_csv`·`savefig` 는 guard 차단(Y15–Y16), `save()`·`plot.save()` 의 상대·절대 경로 이름은 `safe_name` 이 경로를 제거해 전부 `SSDA_EXPORT/export/` 안에만 기록됨(Y56–Y58, Y63). **export 밖 쓰기 0건 확인.**
- **조건식 평가기**: `where`·`define` 식에 함수 호출·속성 접근 주입은 `_ev` 가 허용 표현만 받아 QueryError(Y60–Y61).

## 설계상 잔여 위험(통제 규칙 범위 밖 — 2~3건 확인 지시에 따라 대표 4건)
- **여러 질의의 차분(Y49, Y50, Y51, Y69)**: 통제는 한 표 안의 보충 억제까지만 다루므로, 두 질의의 집계값을 이용자(또는 모형)가 외부에서 빼면 한 표에서 억제된 칸·꼬리 규모를 산술적으로 추정할 수 있음.
  - 다만 ① 가중 인원·합계가 **유효숫자 3자리로 반올림**되어 1인 단위 차분이 소멸하고, ② 고액 임계부터 각 질의 자체가 억제되므로(Y50·Y69의 750백만원 이상), **개인 값 복원 정밀도가 크게 둔화**됨. 이론적 잔여 위험이며 보완안의 결함은 아님.
  - 대응 방향(선택): 질의 로그 기반 차분 탐지(동일 변수의 포개진 조건 연속 질의 경고), 또는 세션 단위 질의 예산.

## 보완안에서 정상 사용 과차단(사용성)
- **무해한 읽기 전용 메서드 차단**: `.to_markdown()`(Y59)·`.encode()`(Y67)는 문자열만 반환하는데, 전자는 `to_` 접두 규칙(파일 쓰기로 오인), 후자는 허용 목록 부재로 차단. 표를 마크다운으로 뽑으려는 정상 요청이 막힘(대안 `Result.to_text()` 존재하나 안내 필요).

## 추가 발견(견고성 결함, 누출은 아님)
- **등급 '제외' 변수 사용 시 미처리 예외(Y31–Y32)**: 식별자(hid 등 grade='제외')를 `where`/`var` 에 쓰면 `_grade_of` 의 `order[gg]` 에서 **KeyError '제외'** 로 실행이 중단됨. 완전 차단되어 누출은 없으나, 깔끔한 `QueryError`("이 변수는 분석에 쓸 수 없음") 대신 스택트레이스를 노출함. `_grade_of` 에 '제외' 처리 추가 권장.
- **define() 단위 손실(Y48)**: 금액 변수로 파생변수를 만들면 '원→만원' 환산이 이어지지 않아 단위 공란·원 단위 원값으로 표시됨. 통제(등급·억제)는 유지되므로 보안 결함은 아니나 표시 일관성 문제.
