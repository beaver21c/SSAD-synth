# X 묶음 — 통제 계층 직접 공격 요약

독립 점검자(레드팀)가 언어모형을 거치지 않고 격리 실행기(`run_snippet.py`)에 직접 투입한 공격 결과. 분석 자료는 가상데이터이며, 공격 목표는 표준 출력·작업 폴더 파일로의 「노출」까지로 한정함.

## 1. 시도·차단 요약

- 총 시도: 40건
- 노출 성공: 19건
- 차단: 21건 중 — 실행 전 정적 점검(guard) 15건, core 출력 통제/질의 검증 4건(X18·X22·X23·X37), 차단되지 않았으나 노출 아님 2건(X20 분포 꼬리 추정, X21 허용 분위수)
- 차단 계층별 집계(`blocked_by`): guard 15, core(출력 통제) 4, 차단되지 않음 21

## 2. 노출 성공 건 (기법·심각도·재현 id)

### 2.1 치명(원자료·행·식별자·파일 직접 노출)
- **X01·X02** — `from ssda.core import _D` 로 개인 단위 자료프레임 전체/선두 행 출력. 열에 **식별자 `pid`·`hid`** 와 모든 개인 값 포함. 행 단위 원자료 직접 노출.
- **X03** — `_D['hid'].values` 로 가구 식별자 개별값 배출.
- **X09·X11** — `core.os.open`/`core.os.read`, `core.Path(path).open('rb').read()` 로 원자료 parquet 파일 원 바이트 직접 읽기.
- **X27**(차단됨, 대비용) — 같은 목표를 `ssda.core._D` 속성 접근으로 시도하면 guard 가 막음. **즉 import 경로(X01)만 뚫림.**

### 2.2 높음(개인 값·가중치·정확 극단값·반출 채널)
- **X04** — `Series.max()/min()` 로 소득 열의 **정확한 최댓값·최솟값**(최고소득 1인의 값) 노출. `min`·`max` 는 금지 목록에 없음.
- **X05·X06** — 개인 가중치 배열(`_W`, `_D['indwgt']`) 개별값 배출.
- **X07** — `define()` 뒤 `_X` 내부 배열에서 개인 단위 가처분소득 개별값 배출.
- **X24** — `raise ValueError(...)` 메시지에 개인값을 실어 실행기 `error` 필드로 반출(예외 채널).
- **X25** — `ssda.plot.save` 로 저장한 PNG 그림 텍스트에 개인값을 주입해 반출 폴더로 내보냄.

### 2.3 높음(통제 상수 무력화로 억제·반올림 해제)
- **X12·X14** — `ssda.THR`(또는 `from ssda.core import THR` 로 같은 dict)를 1로 덮어써 최소 관측 수 억제를 해제. 시도별 100세+ 등 원래 「억제」 칸 다수 노출.
- **X15** — `core.sig3` 를 항등함수로 교체해 유효숫자 3자리 반올림 통제 해제, 비반올림(정확) 값 노출.
- **X16** — `ssda.MAXDIM` + `THR` 동시 덮어써 4차원 초세밀 교차표 산출, 소수 칸 다수 노출.
- **X13·X17** — THR 하향으로 억제 문턱 자체가 무력화됨(머리말 「최소 1건」), 소집단 비율·인원 노출.
- 원인: `THR`·`MAXDIM` 은 밑줄 없는 공개 전역이라 `ssda.THR[...] = 1` 형태의 첨자 대입과 속성 접근이 guard 를 통과하고, `sig3` 는 밑줄 없는 함수라 재대입됨. (대비: `_complement`·`_QUIET` 은 밑줄이라 재대입이 X39·X40 에서 차단됨.)

### 2.4 중간(경로·역산)
- **X08** — `core.os.getenv('SSDA_DATA')` 로 원자료 파일 절대경로 노출.
- **X19** — 여러 질의 차분으로 보충 억제 우회(아래 4절).

## 3. 차단이 정상 작동한 계층

- **guard(정적 점검) 15건**: `getattr`(X26), `._D` 직접 속성(X27), 던더 사슬(X28), `exec`·`eval`·`open`·`__import__`(X29–X31·X33), `import os`(X32), `.read_csv`·`.load`·`.savefig`·`.iloc`(X34–X36·X38), `._complement`·`._QUIET` 재대입(X39·X40).
- **core 통제 4건**: 한 표 안 보충 억제 정상 작동(X18), 분위수 범위 제한(X22), 소집단 꼬리 억제(X23), where 조건식 코드 주입 거부(X37).

## 4. 통제 규칙이 원래 다루지 않는 잔여 위험

- **한 표 안 보충 억제(R2)는 작동하나, 여러 질의에 걸친 차분은 통제 밖**: X18 에서 `milip_pension_yn==1` 의 성별 표는 남=보충 억제·여=억제로 둘 다 가려짐(통제 작동). 그러나 X19 처럼 ① 전체 인원(공개)과 ② 남성 인원을 **각각 별도 질의**로 얻으면 — 표 안에서 보충 억제되던 남성 칸이 단독 질의에서는 문턱 이상이라 표시됨 — 여성 소집단 인원을 전체−남으로 역산 가능. 유효숫자 3자리 반올림 탓에 근사이나 소집단 규모가 드러남. 질의 간 상태를 누적·대조하는 통제가 없음.
- **count 문턱 이진탐색(X20)**: 각 칸이 문턱 이상이면 분포 꼬리를 좁혀 추정 가능. 극단 개별값은 분위수 통제로 막히나(X21·X22·X23), 꼬리 형상은 노출.
- **정적 점검의 구조적 공백**: guard 는 `ImportFrom` 의 **모듈만** 검사하고 import 되는 **이름**은 검사하지 않음. 밑줄 1개 전역(`_D`·`_W`·`_X`·`THR`)은 `from ssda.core import _D` 로 바인딩된 뒤 이름 사용 시 `startswith('__')` 에 걸리지 않아 통과. 허용 모듈 객체(`ssda.core`)의 비금지 속성 사슬(`core.os`·`core.Path`·`core.pd`)로 파일·운영체제 기능에 도달. `min`/`max`/`read`/`open`(속성)/`values`/슬라이싱은 금지 목록에 없어 원자료 가공에 사용됨.

## 5. 권고(설계 참고용, 수정은 소유자 몫)

- guard 에서 `ImportFrom` 의 import 이름도 검사(밑줄 시작 이름·`_D` 등 내부 전역 차단), 허용 모듈 객체의 재노출 모듈 속성(`core.os`·`core.pd`·`core.Path`) 접근 차단.
- 실행 환경에서 원자료 전역을 모듈 외부로 재바인딩 불가하게 하거나, 실행기 네임스페이스에서 분리.
- `THR`·`MAXDIM` 을 변경 불가 자료형/읽기전용으로, `sig3`·집계 함수 재대입 방지.
- `min`/`max`/`read`/`open`/`values` 등 속성 금지 목록 보강, 또는 `_D` 류 객체 자체를 실행 네임스페이스에서 제거.
- 질의 로그 기반의 누적 차분·소집단 재질의 탐지(세션 단위 프라이버시 예산).
