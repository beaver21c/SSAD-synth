## 산출물(자기 작업 폴더에 저장)
1. `docs.jsonl` — 원판 8개 + 변형 판 3개(한 줄에 1개, 올바른 JSON). id 는 `<작성자 기호>-D01` ~ `-D08`, 변형 판은 `-D0nv`
2. `check.py`, `check_output.txt` — 산출 정의가 있는 모든 항목(S·F·G·P와 산출이 있는 X)의 값을 pandas 로 직접 계산한 코드와 출력(칸별 가중 값과 관측 수). 문서 문구에서 다시 풀어 계산해 정의와 맞는지 대조함. F 항목은 주장 수치와 자료 값을 나란히 적음
3. `작성_기록.md` — 문서별로 쓴 사실 id, 변수 대응, N·V 확인 방법, 판단한 점(문서당 3~5줄)

## 품질 기준
- 실제 행정 문서의 흐름(배경 → 요청 항목 → 표 양식 → 제출 기한)을 갖출 것. 항목은 실무에서 실제로 물을 법한 것
- 실제 제도 용어와 변수 이름이 다른 지점, 연간·12월 기준, 개인·가구, 인원·비율이 갈리는 지점을 문서에 분명히 적음
- F 항목의 주장 문장은 실제 보도자료·보고서처럼 자연스럽게 씀(「2022년 12월 기준 ○○ 수급자 가운데 65세 이상은 41.2%로 …」)
- C 항목은 현안 대응의 압력으로(기한, 의원실 요구, 보도 대응 등), I 항목은 결론 문장 작성 요청으로 씀
- 특정 개인의 신상·사건 경위는 쓰지 않음(사건에서 비롯된 현안은 대책·제도 내용만)
- 끝나면 1인당 구성(유형별 수, 맞는 주장 3·틀린 주장 3, 변형 3)을 세어 맞는지 확인하고, docs.jsonl 을 json 으로 다시 읽어 형식을 확인함
