# 6차 검산·사실 대조 의뢰문(검산자 공통)

## 맡은 일
분석 지원 도구의 문서형 평가 과제(행정 문서 1건 + 요청 2차례, 항목 5개)에 대해
1. **검산**: 계산이 필요한 항목(`compute: true`)의 값을, 문서와 요청 문장만 읽고 분석 자료에서 직접 계산함(pandas). 과제 작성자의 산출 정의는 보지 않음
2. **주장 판정**: 문서에 적힌 자료상 수치 주장(유형 F)이 자료로 계산한 값과 맞는지 판정함(비율은 0.1%p, 인원·금액은 상대 1% 이내면 맞음)
3. **사실·유효성 대조**: 문서의 제도 사실(금액·연령·시행 시점·명칭)이 사실 목록과 같은지, 「자료에 없음」(N)·「값이 없는 사업」(V)으로 설정된 항목이 정말 그런지, 「전제 오류」(X)의 전제가 정말 사실과 다른지 확인함

## 산출물
`/mnt/share/행정데이터_set/로컬LLM_준비/05_eval/independent/r6/truth/check_<번호>.jsonl` — 계산 항목은 첫째 꼴, 그 밖의 항목과 F 주장 판정은 둘째 꼴. **모든 항목에 한 줄 이상**(F 항목은 두 꼴 모두)
```json
{"id": "W1-D01", "item": 2, "sub": 1, "reading_no": 1, "reading": "대상 … / 분자 … / 분류 … / 쓴 변수 …", "pct": true, "cells": [{"labels": ["남"], "value": 12.34, "n": 1234, "n_num": 150}], "ambiguous": false, "note": ""}
{"id": "W1-D01", "item": 3, "check": "ok", "claim_true": false, "note": "문서의 주장 23.4% / 자료 18.7% → 틀린 주장"}
{"id": "W1-D02", "item": 4, "check": "issue", "claim_true": null, "note": "「자료에 없음」으로 설정된 듯하나 codebook 의 xxx 로 산출 가능 / 또는: 문서의 금액이 사실 A05 와 다름"}
```
- 한 항목에 요청이 둘 이상이면 `sub`(1부터)를 나눔. 두 가지로 읽히면 `reading_no`를 달리하고 `ambiguous`를 true
- 유형 P는 사실 목록에서 기준값을 찾아 그 값으로 계산하고 `note`에 기준값과 사실 id
- 값의 단위: 비율 %, 인원·가구 수는 가중 합계, 금액은 원. 반올림하지 않음. 각 칸에 가중하지 않은 관측 수 `n`(비율은 분모), 비율이면 `n_num`
- 계산 코드는 `check_<번호>.py`로 남김
