# W2 작성 기록(6차 문서형 과제, 건강보험·의료·장기요양·노인·장애인 서비스)

## 구성
- 원판 8개(W2-D01~D08), 변형 판 3개(W2-D02v·D03v·D06v), 항목 40개
- 유형별: S 18, F 6(맞는 주장 3: D02-3·D03-2·D05-2 / 틀린 주장 3: D01-2·D03-1·D06-3), G 2, P 2, N 3, V 2, X 2, C 3, I 2
- 문서 유형: 국회 요구자료 2(D01·D06), 감사 질의 2(D02·D07), 업무보고 작성 2(D04·D08), 보도자료 검토 1(D03), 민원 회신 검토 1(D05)
- 영문 표현 1개(D08-3). 문서 일자는 2022년 연간 자료가 집계된 뒤인 2023년 1~3월로 두고 현안·제도 내용은 2021~2022년 사실만 씀
- 산출 정의 계산·독립 계산 대조·구성 점검: `check.py` → `check_output.txt`(독립 계산 불일치 0, 관측 30건 미만 주된 칸 없음, 같은 대화 안 차이 집단 1~29건 없음)

## 문서별 기록

### W2-D01 국회 요구자료 — 부과체계 2단계 개편 이후 가입자 현황
- 사실: B01(최저보험료 월 19,500원, 재산공제 5,000만 원), B02(피부양자 소득요건 3,400만→2,000만 원), B12(가입유형 용어)
- 변수: 가입유형 `nhi_type`(12월 기준 6구분), 피부양자 = `nhi_type == 6`, 지역 세대 = 세대주 `nhi_type == 1`, 12월 산정보험료 `nhi_premium_cal`(세대주 행에 세대 월 보험료)
- N(항목 4): 피부양자 자격 상실·전환 이력 변수 없음(codebook 「자격」 변수는 자격정지 `nhi_disentitle_*`뿐)
- 판단: G는 19,500원 정확값 세대가 1,717건이라 「이하」(40.0%)와 「미만」(30.0%)이 갈림. 건강보험 세대를 주민등록 가구와 구분하도록 문서에 「세대주 인원으로 셈」을 적음. F 주장 17.8%(자료 13.5%)

### W2-D02 감사 질의 — 본인부담상한제 지원 규모(변형 D02v)
- 사실: B06(2022년 상한액 1분위 83만 원~10분위 598만 원)
- 변수: 지원 여부 `nhi_ceiling_subsidy_yn == 1`(0·결측 혼재), 지원액 `nhi_ceiling_subsidy_amt`(사전·사후 합계), 외래·입원 본인부담금 `nhi_out_fee`·`nhi_in_fee`(의과 기준)
- 판단: 사후 환급금 변수 `nhi_ceiling_amt`는 가입자 전원에 양수가 있어 쓰지 않음. G(항목 4)는 한쪽 결측을 0으로 본 합계(define_sum과 같은 처리)가 83만 원 초과. F 50.6%는 자료값 그대로(맞는 주장)이며 공단 발표 52.6%와 다름
- 변형: 「본인부담금 상한제」(aliases)와 「초과분을 공단이 부담해 준 사람」(서술)로 바꾸고 항목 순서를 3→1→2→4로 바꿈

### W2-D03 보도자료 검토 — 장기요양 인정자 100만 명(변형 D03v)
- 사실: B19(인정자 953,511→1,019,130명, 재가 15%·시설 20%), B05(장기요양보험료율 건강보험료 대비 12.27%, 소득 대비 0.86%), B21(V 근거)
- 변수: 연간 수급 `ltcare_bn_yn == 1`(0/1, 결측 없음), 판정 등급 `ltcare_grade`, 시설급여 `ltcare_institute_yn`, 재가 본인부담 `ltcare_hbn_fee`, 직장 장기요양보험료 `nhi_premium_ltcare_amt1_y`(건강보험료의 정확히 12.27%)
- X(항목 4): 「소득의 12.27%」 전제. V(항목 5): 「치매 치료관리비 지원사업」은 값없는_사업.tsv에 있고 codebook에 없음(codebook 치매 변수는 산정특례 `nhi_special4_yn`뿐)
- 판단: 연간 수급자(가중 58.8만 명)와 연말 인정자 공식 통계의 차이를 문서에 적음. 재가 본인부담 평균은 0원 포함으로 문서에 고정. F 9.8%(자료 6.1%)는 틀린 주장, 4등급 48.7%는 맞는 주장. 65세 미만 수급자 44건으로 항목 1·2 사이 차이 집단 30건 이상

### W2-D04 업무보고 작성 — 노인맞춤돌봄·공익활동 실적
- 사실: B20(2020년 1월 6개 사업 통합, 대상 50만 명), B22(노인일자리 84.5만 개, 공익활동 월 30시간·월 27만 원)

### W2-D05 민원 회신 검토 — 의료급여 2종 입원 본인부담·노인 임플란트

### W2-D07 감사 질의 — 산정특례 암 등록자와 상한제

## 작업 중 사건
- 공용 임시 폴더(scratchpad)의 같은 이름 조립 스크립트가 다른 작성자 파일로 바뀌어 있었고, W2 재조립 명령이 그 스크립트를 1회 실행함. 출력 경로 한 줄만 확인했으며 내용은 열지 않음. 이후 W2 수정은 전용 하위 폴더의 패치 스크립트로 `docs.jsonl`에 직접 적용함
