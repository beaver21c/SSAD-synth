- 산출물: `docs.jsonl`(원판 8 + 변형 판 3, 11줄), `check.py`, `check_output.txt`
- 조립 스크립트: `scratchpad/w1_author_only/build_docs_w1.py`(W1 전용 폴더. 공용 임시 폴더에 처음 둔 조립 스크립트를 다른 작성자가 실행해 docs.jsonl 이 한 차례 덮어써졌다는 조정자 알림에 따라, 이 스크립트로 다시 만들고 손으로 고친 내용이 들어갔는지 확인함)
- 구성: S 18, F 6(맞음 3·틀림 3), G 2, P 2, N 3, V 2, X 2, C 3, I 2. 문서 유형 5종. 영문 표현 1개(D03-3). 변형 판 D01v·D03v·D07v
- 공통 판단: 「받지 않은 사람」은 `not (x == 1)`(12월 변수 0 행 포함). 가구 항목은 가구주 행 + 가구 가중치. 모든 칸·분자·여집합 관측 30건 이상, 같은 대화 안 대상 차이 집단 30건 미만 0건(check.py 점검)

## W1-D01 국회 요구자료 — 기초연금(2023. 2.)
- 사실: A09(2022년 기준연금액 30만 7,500원), A10(40만 원은 국정과제 목표)
- 변수: 연간 수급 `bp_yn1`, 12월 수급 `bp_yn2`, 수급 유형 `bp_type`(12월), 급여액 `bp_amt`
- F(틀림): 369만 원은 30만 7,500원×12로 만든 값. 자료 값 316.4만 원(차이 16.6%)
- X: 배경의 「2022년부터 기준연금액 월 40만 원」. 산출 가능 부분은 12월 단독가구 수급자 수
- 판단: 연간(항목 1·3)과 12월(항목 2·4) 대상 차이 95건으로 30건 이상. C는 최댓값·최솟값

## W1-D02 감사 질의 — 생계급여 부양의무자 기준 폐지 이후(2023. 3.)
