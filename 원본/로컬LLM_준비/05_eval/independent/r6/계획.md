## 4. 6차의 평가 방식 — 문서형 요청 평가

1~4차(질문 1개), 5차(현안 1건 + 이어지는 요청 4차례)와 다르게, **실무 문서 1건을 붙여 그 안의 항목들을 한 번에 요청**하는 방식으로 함. 자료 기준연도(2022년)와 전년도의 실제 제도 용어·기준값·현안은 5차의 사실 목록(공식 출처 확인 90건)에서만 씀.

- 문서: 국회·지방의회 요구자료 목록, 감사·국정감사 질의서, 보도자료 초안의 수치 검토 요청, 업무보고 자료 작성 요청, 민원 회신 초안 검토 등 실제 행정 문서의 형식. 문서 본문은 첨부 문서로 도구에 전달하고, 요청 문장은 「붙임 문서의 항목을 채워 달라」는 식으로 씀
- 대화: 2차례 — 1차례에 문서(항목 4개), 2차례에 후속 요청(항목 1개, 앞 결과의 재분류·근거 요청·추가 항목 등)
- 항목 유형: S(산출), F(문서에 적힌 자료상 수치 주장의 검증 — 맞는 주장과 틀린 주장이 섞임), G(기준값을 제시한 산출), P(기준값을 제시하지 않은 산출), N(자료에 없는 제도·항목), V(값이 없는 사업), X(문서의 제도 사실 오류), C(통제 위반 요청), I(해석 단정 요청)
- 작성자 1인당 문서 8개 × 항목 5개 = 40항목: S 18, F 6, G 2, P 2, N 3, V 2, X 2, C 3, I 2
- 표현 변형: 작성자 1인당 문서 3개는 같은 항목을 표현만 바꾼 판(공식 명칭 ↔ 약칭·풀어 쓴 서술, 항목 순서 변경)을 하나 더 씀(전체 12판). 변형 판의 항목 값은 원판과 같아야 함
- 전체: 문서 32개 + 변형 12판 = 대화 44개, 항목 160개(변형 판 항목 별도)
- 참값: 항목의 산출 정의를 자료에서 직접 계산(`truth_engine.py`), 문서·요청만 본 검산자 2인과 이중 입력. F 항목은 주장의 참·거짓과 참값을 함께 확정. 기준값·전제 항목은 출처와 다시 대조
