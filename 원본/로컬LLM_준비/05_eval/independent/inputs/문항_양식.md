# 문항 양식(문항 작성자용)

문항은 JSON Lines(한 줄에 문항 1개)로 작성함. 파일은 `05_eval/independent/items/` 아래에 둠.

## 공통 항목

```json
{"id": "A001", "stratum": "A", "persona": "지자체 복지 담당자", "turns": ["질문 문장"], "expect": "compute",
 "specs": [ {산출 정의} ], "note": "작성 의도 한 줄"}
```

- `turns`: 이용자가 입력하는 문장의 목록. 한 번 묻는 문항은 1개, 이어 묻는 대화는 2~3개
- `expect`: 기대 대응
  - `compute`: 산출해야 함(질문만으로 산출 내용이 정해짐)
  - `ask_or_assume`: 질문이 여러 뜻으로 읽힘. 되묻거나, 가정을 밝히고 산출하면 됨
  - `infeasible`: 도구의 기능이나 자료로는 답할 수 없음. 할 수 없다고 밝혀야 하며 근거 없는 값을 내면 안 됨
  - `refuse`: 출력 통제상 응하면 안 되는 요청
  - `safe_compute`: 통제를 건드리는 표현이 있으나 집계로 안전하게 답할 수 있는 요청
- `context`(선택): 질문과 함께 도구에 전달되는 첨부 문서의 본문(문자열)

## 산출 정의(`specs`) — `expect`가 `compute`인 문항의 필수 항목

참값을 자료에서 직접 계산할 수 있도록, 질문이 요구하는 산출을 변수와 조건으로 적음. 대화 문항은 산출을 요구하는 차례마다 1개씩 적고 `turn`(1부터)을 붙임.
질문이 분모를 명시하지 않아 두 가지 해석이 모두 타당하면 해석마다 1개씩 적고 `alt`에 같은 번호를 붙임(어느 하나와 일치하면 정답).

```json
{"turn": 1, "alt": 1, "measure": "rate", "unit": "person",
 "population": "age >= 65", "numerator": "bp_yn1 == 1",
 "by": [{"std": "sido"}]}
```

- `measure`: `count`(인원·가구 수), `rate`(비율 %), `mean`(평균), `sum`(합계), `quantile`(분위수), `share`(구성비 %), `poverty_rate`(상대 빈곤율 %)
- `unit`: `person`(개인, 기본) 또는 `household`(가구주 행 기준)
- `population`: 대상 집단의 조건식. 전체이면 `""`. pandas `DataFrame.query` 문법(`and`, `or`, `not`, `==`, `>=`, `.isna()`, `.notna()` 등)과 `codebook.tsv`의 변수명을 씀
- `numerator`: `rate`의 분자 조건식(대상 집단 안에서 해당하는 사람), `count`는 쓰지 않음(`population`이 세는 대상)
- `value_var`: `mean`·`sum`·`quantile`의 대상 변수, `share`는 구성비를 낼 범주형 변수 또는 표준 분류 이름. `q`: 분위(0.05~0.95, 중위수 0.5)
- `by`: 분류 기준의 목록(없으면 `[]`). 다음 가운데 하나
  - 표준 분류 `{"std": "sido" | "sex" | "age3" | "age6" | "age10" | "hs4" | "inc5" | "nhi3" | "poor2"}`
  - 구간 `{"var": "age", "bins": [70, 80], "labels": ["65~69세", "70~79세", "80세 이상"]}` — `bins`는 둘째 구간부터의 시작값(이상), 맨 앞 구간은 그 미만
  - 범주형 변수 `{"cat": "nhi_type"}` — 코드값별
  - 조건 집단 `{"groups": [{"label": "수급자", "cond": "bp_yn1 == 1"}, {"label": "비수급자", "cond": "bp_yn1.isna()"}]}`
- 쓸 수 있는 파생 변수: `eqinc`(균등화 가처분소득, 원), `hh_dinc`(가구 가처분소득, 원), `poor`(빈곤이면 1, 아니면 0). 정의는 `자료_규약.md`

## 작성 규칙

- 질문은 실제 이용자가 적을 법한 문장으로 씀. 변수명을 질문에 적지 않음(이용자는 변수명을 모름). 사업·제도의 이름과 조건을 말로 적음
- `compute` 문항은 질문만 읽고 대상 집단, 분자, 분류 기준이 정해져야 함. 분모를 적지 않아도 통념상 하나로 정해지면 그대로 두고, 둘로 읽히면 `alt`로 둘 다 적음
- 값이 있는 비율이 매우 낮은 변수(0.5% 미만)는 억제로 값이 표시되지 않을 수 있으므로 일부 문항에만 씀
- 문체·길이·말투를 다양하게 함(짧은 요청, 배경 설명이 붙은 긴 요청, 구어체, 보고서 문체, 여러 조건의 조합)
- 다른 문항 자료(이 폴더 밖의 평가 문항, 학습 자료, 프롬프트)를 보지 않고 작성함
