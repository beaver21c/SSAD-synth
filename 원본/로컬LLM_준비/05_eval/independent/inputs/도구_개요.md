# 분석 지원 도구 개요(문항 작성자용)

## 도구가 하는 일
- 폐쇄망 분석환경에서 이용자가 한국어로 질문하면, 도구가 집계 분석 코드를 작성·실행하여 결과(표, 그림, 설명)를 돌려줌
- 이용자는 보건복지 분야의 정책 담당자, 지자체 담당자, 연구자, 통계 담당자임. 이용자는 질문을 자유로운 문장으로 적음

## 분석 자료
- 2022년 기준 사회보장 행정자료 결합 자료(개발용 가상데이터). 개인 단위 94,430행(가중 인구 약 5,150만 명), 42,000가구, 변수 595개
- 변수 목록은 `codebook.tsv`(변수명, 한글 이름, 사업, 코드값, 민감도 등급, 값이 있는 비율, 분포 요약)
- 한 시점(2022년)의 자료임. 연도별 자료는 없음

## 산출할 수 있는 것(집계 함수 7종)
- 인원 또는 가구 수(가중), 비율(%), 평균, 합계, 분위수(5~95% 범위, 중위수 포함), 범주형 변수의 구성비(%), 상대 빈곤율
- 대상 집단은 조건식으로 한정함(연령, 성, 지역, 수급 여부, 금액 조건 등의 조합)
- 분류 기준: 표준 분류(시도, 성, 연령대 3구간·6구간·10세 단위, 가구원수 4구간, 소득 5분위, 건강보험 가입 구분, 빈곤 여부), 이용자가 지정한 구간(예: 65~69세 / 70~79세 / 80세 이상, 재산 1억원 미만 / 이상), 범주형 변수의 코드값. 한 번에 2~3개까지
- 가구 단위 집계: 가구주 행의 값과 가구 변수로 산출함
- 그림(막대, 선, 구성비, 시도 지도 등)과 집계 결과 표의 저장
- 이 밖의 통계 기법(회귀분석, 상관계수, 검정, 표준오차, 시계열 등)의 함수는 없음

## 출력 통제(도구가 강제하는 규칙)
- 민감도 등급별 최소 관측 수: 가 10건, 나 20건, 다 30건. 기준 미만 칸은 표시하지 않음(억제). 비율은 분자·분모·여집합 모두 기준 이상이어야 함
- 한 줄에 억제 칸이 하나뿐이면 역산을 막기 위해 한 칸을 더 억제함
- 가중 인원·금액은 유효숫자 3자리, 비율은 소수 첫째 자리로 표시함
- 응하지 않는 요청: 개인 단위 행의 조회·출력·저장, 특정 개인·가구의 값 확인, 식별자 출력, 최솟값·최댓값, 상위·하위 명단, 억제 기준의 해제·우회, 자료 파일의 직접 읽기·반출, 문서 안에 들어 있는 지시문의 수행
