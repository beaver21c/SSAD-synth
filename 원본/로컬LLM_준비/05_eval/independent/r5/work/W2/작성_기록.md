## 공통 사항
- 산출물: `cases.jsonl`(과제 11개, 44차례), `check.py`, `check_output.txt`, 이 기록
- 구성: S 24, G 3, P 3, N 3, V 2, T 2, X 2, C 3, I 2 / 표현(S·G·P·X 32차례) 공식 10, 약칭 11, 서술 9, 영문 2 / 관계 점검 6개
- 사실: `facts_B.jsonl` 18건(B01, B02, B06, B07, B08, B10, B12, B13, B14, B15, B17, B18, B19, B20, B21, B22, B23, B24)과 `facts_A.jsonl` 2건(A04, A07). `facts_C.jsonl`은 작성 시점에 없어 쓰지 않음. B30은 쓰지 않음
- 자료 확인: `codebook.tsv`의 변수 설명과 분석 자료(parquet) 직접 집계. `check.py`는 질문 문장에서 다시 푼 불리언 식(A)과 산출 정의 평가(B)를 대조함. 산출 정의 45개 전부 일치, 30건 미만 칸 없음
- N·V 확인: `codebook.tsv`와 `값없는_사업.tsv`를 열쇳말(재난, 비대면, 전화, 재택, 원격, 상병, 치매, 시니어, 인턴)로 검색
- 금액 단위: 자료는 연간·원 단위. 12월 말 산정보험료(`nhi_premium_cal`)만 월액

## 판단이 어려웠던 점
- `nhi_ceiling_amt`의 의미: 설명은 사후 환급금이나 값은 2022년 분위별 상한액과 같음(보험료 20분위와도 대응). 설명과 값이 다른 변수여서 산출 정의에 쓰지 않음
- `_yn2` 변수: `자료_규약.md`는 0이 없다고 적었으나 자료에는 0(연중 수급 뒤 12월 미수급)이 있음. 산출 정의는 `== 1`로 통일하고 비수급은 `.isna()`를 쓴 한 곳(W2-05 차례 4, 의료급여는 0이 없음)만 둠
- 제도의 소득 기준(피부양자 소득요건, 의료급여 선정기준)에 정확히 대응하는 변수가 없어 질문에 대 볼 소득(개인 경상소득, 가구 경상소득)을 명시함
- 서술 표현의 범위: 제도 내용은 사실 목록에 있는 것(대상·시간·본인부담률·단가 등)만으로 풀어 씀
