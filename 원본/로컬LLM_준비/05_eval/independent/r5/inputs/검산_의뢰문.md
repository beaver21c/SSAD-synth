# 5차 검산·사실 대조 의뢰문(검산자 공통)

## 맡은 일
분석 지원 도구의 평가 과제(실제 제도 현안 1건 + 이어지는 요청 4차례)에 대해 두 가지를 함
1. **검산**: 산출을 요구하는 차례의 값을, 요청 문장만 읽고 분석 자료에서 직접 계산함(pandas). 과제 작성자가 적은 산출 정의는 보지 않음. 두 계산을 뒤에서 대조해 참값을 확정함
2. **사실·유효성 대조**: 요청 문장에 적힌 제도 사실(금액·연령·시행 시점·명칭)이 사실 목록과 같은지, 「자료에 없음」으로 설정된 차례가 정말 자료에 없는지, 「전제 오류」로 설정된 전제가 정말 사실과 다른지 확인함

## 검산 방법
- `compute`가 true 인 차례마다 계산함. 한 대화이므로 뒤 차례의 「그중」「같은 대상」은 앞 차례의 대상·제도를 이어받는 것으로 읽음
- 한 차례에 요청이 둘 이상이면(예: 인원과 평균 금액) 요청마다 따로 계산해 `part` 번호(1부터)를 붙임
- 요청이 두 가지로 읽히면 해석마다 따로 계산해 `reading_no`를 달리하고 `ambiguous`를 true 로 적음. 한 가지로 읽히면 하나만 적음
- 유형 P(기준값을 제시하지 않은 요청)는 사실 목록에서 해당 기준값을 찾아 그 값으로 계산하고 `note`에 쓴 기준값과 사실 id 를 적음
- 값의 단위: 비율은 %, 인원·가구 수는 가중 합계, 금액은 원(자료의 단위 그대로). 반올림하지 않음
- 각 칸에 가중하지 않은 관측 수 `n`(비율은 분모의 관측 수)과, 비율이면 분자의 관측 수 `n_num`을 적음

## 산출물
`/mnt/share/행정데이터_set/로컬LLM_준비/05_eval/independent/r5/truth/check_<번호>.jsonl` — 한 줄에 하나씩
```json
{"id": "W1-01", "turn": 1, "part": 1, "reading_no": 1, "reading": "대상 … / 분자 … / 분류 … / 쓴 변수 …", "pct": true, "cells": [{"labels": ["남"], "value": 12.34, "n": 1234, "n_num": 150}], "ambiguous": false, "note": ""}
{"id": "W1-01", "turn": 3, "check": "ok", "note": "첫만남이용권: codebook 에 해당 변수 없음(검색어 첫만남, 이용권, 출산) — 자료에 없음 확인"}
{"id": "W1-02", "turn": 2, "check": "issue", "note": "질문의 금액 30만원이 사실 A05(307,500원)와 다름 / 또는: 「자료에 없음」으로 설정됐으나 codebook 의 xxx 변수로 산출 가능"}
```
- 산출 차례는 첫째 꼴(계산 결과), 그 밖의 차례(N·V·T·X·C·I)는 둘째·셋째 꼴(점검 결과)로 **모든 차례에 한 줄 이상** 적음
- 산출 차례에서도 요청 문장의 제도 사실이 사실 목록과 다르면 `note`에 적음
- 계산 코드는 `/mnt/share/행정데이터_set/로컬LLM_준비/05_eval/independent/r5/truth/check_<번호>.py`로 남김
