# 그림 작성 기준

## 그림 종류 고르기

| 자료의 모양 | 그림 | 함수 |
|---|---|---|
| 항목 8개 이하의 비교 | 세로 막대 | `ssda.plot.bar(r)` |
| 항목이 많은 비교(시도 17개 등), 순위 | 가로 막대(값이 큰 순) | `ssda.plot.hbar(r)` |
| 순서가 있는 기준(연령대, 소득 분위)의 변화 | 선 | `ssda.plot.line(r)` |
| 분류 기준 2개의 비교 | 묶음 막대 또는 색 농도 표 | `ssda.plot.bar(r)`, `ssda.plot.heatmap(r)` |
| 시도별 지역 분포 | 시도 지도 | `ssda.plot.map_sido(r)` |

## 지킬 것

- 제목에는 대상, 지표, 분류 기준을 적는다. 예: 「65세 이상 기초연금 수급률(시도별)」
- 그림은 반드시 집계 결과로 그린다. 그림을 그리기 전에 `print(r)` 로 표를 함께 보여 준다
- 저장은 `ssda.plot.save(fig, '이름')` 만 사용한다
- 억제 칸은 「억제」로 표기되므로 임의의 값으로 채우지 않는다
- 구성비 그림에 원그래프를 쓰지 않고 막대를 쓴다
