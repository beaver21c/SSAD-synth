# 분석 요령

## 수급률: 분모를 제도의 대상 집단으로 둔다

- 기초연금 수급률: `ssda.rate('bp_yn1 == 1', where='age >= 65')`
- 국민연금 가입률: `ssda.rate('np_yn == 1', where='age >= 18 and age <= 59')`
- 생계급여 수급률(전체 인구 대비): `ssda.rate('nbls_live_yn1 == 1')`
- 분모를 지정하지 않으면 전체 인구가 분모가 된다. 질문에 대상이 없으면 제도의 대상 연령을 분모로 쓰고 그 사실을 밝힌다

## 여부 변수의 뜻: _yn1 은 연간, _yn2 는 12월 기준

- `_yn1`: 2022년 1년 동안 한 번이라도 수급·가입했으면 1
- `_yn2`: 2022년 12월 기준 수급·가입이면 1
- 질문이 시점을 밝히지 않으면 연간 기준(_yn1)을 쓰고 그 사실을 밝힌다
- 여부 변수의 해당하지 않는 사람은 결측 또는 0으로 적혀 있으므로 비수급자는 `not (변수 == 1)` 로 쓴다

## 중복 수급: 두 조건을 and 로 묶는다

- 기초연금과 생계급여를 함께 받는 65세 이상 비율: `ssda.rate('bp_yn1 == 1 and nbls_live_yn1 == 1', where='age >= 65')`
- 생계급여 수급자 중 의료급여 수급권자 비율: `ssda.rate('nbls_medi_yn1 == 1', where='nbls_live_yn1 == 1')`

## 금액: 수급자 평균과 대상 인구 평균을 구분한다

- 수급자 1인당 평균: `ssda.mean('bp_amt', where='bp_yn1 == 1')` (단위 만원)
- 총 지급액: `ssda.total('bp_amt')` (단위 만원). 조원으로 바꾸려면 값을 1억으로 나눈다
- 금액 변수는 원 단위로 저장되어 있고 결과는 만원으로 환산된다

## 소득과 빈곤

- 균등화 가처분소득 `eqinc` = 가구 가처분소득 ÷ √가구원수 (만원)
- 소득 5분위 `inc5` 는 균등화 가처분소득의 개인 5분위
- 상대 빈곤율: `ssda.poverty_rate(by='age3')`. 빈곤선은 균등화 가처분소득 중위값의 50%
- 개인 소득 변수: p_labinc(근로), p_binc(사업), p_pubinc(공적이전), p_tax(세금), p_soin_amt(사회보험료), p_dinc(가처분)
- 가구 소득 변수: h_minc(일차소득), h_pubinc(공적이전), h_dinc(가처분). 가구원 모두에게 같은 값이 들어 있다

## 가구 단위 분석

- 가구 수, 가구 비율은 `unit='가구'` 를 준다. 가구주 행과 가구 가중치로 집계된다. 가구주의 연령·성 조건은 where 에 `age`, `gender` 조건으로 쓰고(가구주 인자는 따로 없음) `hnum == 1` 은 1인 가구에만 쓴다
- 받는 사람과 받지 않는 사람의 비교는 여부 변수를 by 에 쓰면 해당 / 해당 없음의 두 항목으로 나온다. 집단별 구성비는 `ssda.share(변수, where=…, by=분류 기준)`
- 1인 가구 비율: `ssda.rate('hnum == 1', unit='가구')`
- 가구 재산 평균: `ssda.mean('h_prop', unit='가구', by='hs4')`

## 지역 비교

- 시도별 비교는 `by='sido'`. 그림은 `ssda.plot.hbar(r)` 또는 `ssda.plot.map_sido(r)`
- 시군구 단위는 분석 함수로 제공하지 않는다. 대시보드의 지표 지도를 안내한다

## 질문이 모호할 때

- 대상 집단, 기준 시점(연간·12월), 분류 기준이 분명하지 않고 결과가 크게 달라질 수 있으면 한 번 되묻는다
- 되묻지 않아도 되는 경우에는 적용한 가정을 계획에 밝히고 진행한다
