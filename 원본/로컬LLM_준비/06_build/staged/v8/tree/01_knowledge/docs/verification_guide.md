# 검증 요령

## 검증 결과의 구성과 수준

- 코드를 실행하면 [실행 결과] 다음에 [검증 결과]가 함께 돌아온다. 실행기가 집계 결과마다 자동으로 점검한 내역이다
- 수준은 세 가지다. 경고: 코드를 고쳐 다시 실행한다. 주의: 「유의 사항」에 밝힌다. 참고: 해석에 쓴다
- 한 줄 형식: `- r: 이상 없음 · 억제 0/17칸 · 분류하지 않은 전체 값 67.5%`. 결과 이름 다음에 판정, 억제 칸 수, 전체 값이 온다
- 경고를 고치지 않는 경우는 질문이 그 조건을 명시했을 때뿐이다. 그때는 사유를 「유의 사항」에 적는다

## 분모 경고에 대처하기

- 뜻: 분자(예: 기초연금 수급자)에 해당하는 사람이 한 명도 없는 연령대가 분모의 15% 이상을 차지한다. 제도의 대상이 아닌 사람이 분모에 들어가 수급률이 낮게 나온다
- 질병처럼 연령에 따라 드물 뿐인 지표에는 이 경고가 뜨지 않는다. 경고가 없다고 분모가 옳다는 뜻은 아니므로 변수 카드의 「추출 대상」을 함께 확인한다
- 대처: `where`를 제도의 대상 집단으로 한정해 다시 실행한다. 예: `ssda.rate('bp_yn1 == 1', where='age >= 65', by='sido')`
- 대상 연령은 변수 카드의 「추출 대상」과 규칙 카드에서 확인한다. 기초연금·장기요양·노인일자리는 65세 이상, 국민연금 가입은 18~59세, 고용보험은 18~64세, 보육료는 6세 미만, 아동수당은 8세 미만
- 질문이 「전체 인구 대비」를 명시한 경우에는 고치지 않고 「유의 사항」에 분모가 전체 인구임을 적는다
- 대상을 성별·지역으로만 한정한 경우에도 같은 경고가 나온다. 연령 조건을 함께 넣는다: `where='age >= 65 and gender == 2'`
- 질문이 대상을 명시했는데도 경고가 남으면(예: 65세 이상을 대상으로 했으나 해당자가 75세 이상에만 있음) 고치지 않고 그 사실을 「유의 사항」에 적는다

## 0 비교 경고에 대처하기

- 뜻: 수급·가입 여부 변수는 해당하면 1이고, 해당하지 않으면 결측(일부 변수는 0)이다. 0이 없는 변수에 `변수 == 0`을 쓰면 해당 인원이 0이 된다
- 대처: 해당하지 않는 집단은 `not (변수 == 1)`로 쓴다. 예: `ssda.rate('not (bp_yn1 == 1)', where='age >= 65')`

## 분류 누락 주의에 대처하기

- 뜻: 분류 기준으로 쓴 변수에 값이 없는 대상이 표에서 빠졌다. 예: 수급 유형(`bp_type`)으로 나누면 비수급자는 표에 없다
- 대처: 빠진 비율을 「유의 사항」에 적는다. 의도와 다르면 대상(`where`)을 값이 있는 집단으로 한정하거나 다른 분류 기준을 쓴다

## 요청 반영 주의와 0 포함 주의에 대처하기

- 요청 반영 주의: 질문에 적힌 조건(연령, 성, 1인 가구, 빈곤층, 소득 분위, 지역, 가구 단위, 그림, 저장)에 해당하는 표현이 코드에 없다는 뜻이다. 질문을 다시 읽고 빠뜨린 조건이면 `where`·`by`·`unit`에 넣어 다시 실행한다
- 이 점검은 낱말 수준의 대조다. 「수급자 가운데」「이용자의」처럼 제도 변수로 정해지는 대상은 점검되지 않으므로 코드를 쓰기 전에 대상 조건을 스스로 확인한다
- 0 포함 주의: 금액의 평균·분위수를 구할 때 계산 대상의 20% 이상이 0이다. 「근로소득이 있는 사람」처럼 금액이 있는 사람만 대상이면 `where='p_labinc > 0'`을 넣어 다시 실행한다. 0을 포함한 전체 평균이 목적이면 그대로 두고 「유의 사항」에 0의 비율을 적는다

## 제도 용어를 풀이하고 확인하기

- 질문에 제도명·약어·통칭이 나오면 [참고 자료]에 「제도 설명」 카드가 붙는다. 정식 명칭, 구성 급여, 변수가 적혀 있다. 예: 국기초 = 국민기초생활보장제도(생계·의료·주거·교육급여)
- 여러 급여나 내역을 묶어 부르는 말에 내역이 없으면 「용어 확인」 카드가 붙는다. 「확인 필요」로 되묻는 경우, 기본 해석으로 진행하는 경우, 자료에 없는 항목인 경우가 있다
- 「본인부담금」은 외래 본인부담금, 입원 본인부담금, 둘의 합계, 요양기관 종별 금액 가운데 무엇인지 되묻는다. 장기요양·장애인활동지원의 본인부담금은 다른 변수다
- 「하나라도 받는 사람」으로 답을 받으면 조건식을 or 로 묶는다: `ssda.rate('nbls_live_yn1 == 1 or nbls_medi_yn1 == 1 or nbls_house_yn1 == 1 or nbls_edu_yn1 == 1')`
- 「모두 더한 금액」으로 답을 받으면 합계 변수를 만든다: `ssda.define_sum('fee_all', ['nhi_out_fee', 'nhi_in_fee'], '외래·입원 본인부담금')` 다음에 `ssda.mean('fee_all', by='age6')`
- [검증 결과]에 용어 주의가 뜨면 되묻지 않고 한 가지 해석으로 산출했다는 뜻이다. 어떤 변수로 해석했는지와 다른 해석이 가능함을 「유의 사항」에 적는다

## 억제 주의에 대처하기

- 뜻: 표시되지 않는 칸이 절반을 넘는다. 표를 그대로 쓰기 어렵다
- 대처: 분류 기준을 하나로 줄이거나 범주가 적은 기준(age6 대신 age3)으로 바꿔 다시 산출하는 방법을 제안한다. 억제 기준을 바꾸거나 억제 칸의 값을 역산하지 않는다

## 전체 값을 해석에 쓰기

- [검증 결과]의 「분류하지 않은 전체 값」은 같은 대상의 전체 평균 수준이다. 집단별 값을 설명할 때 기준으로 쓴다
- 예: 「시도별 수급률은 서울 72.1%로 가장 높고 전남 61.4%로 가장 낮음. 전체 값은 67.5%임」
- 전체 값이 집단별 값의 범위 밖에 있으면 주의가 뜬다. 분류 누락이나 조건식을 확인한다

## 기준 시점과 값 있는 대상

- 참고(기준 시점): `_yn1`은 연간 기준, `_yn2`는 12월 기준이다. 어느 기준을 썼는지 「유의 사항」에 적는다
- 참고(값 있는 대상): 평균·분위수는 값이 있는 사람만으로 계산된다. 급여액 평균은 수급자 평균이며 대상 인구 전체의 평균과 다르다. 「유의 사항」에 계산에 포함된 비율을 적는다

## 그림 점검과 변수 주의

- 그림은 저장 전에 자동으로 점검된다: 제목, 항목 이름 겹침, 그림 밖으로 잘린 글자, 값 표기 겹침. 겹친 항목 이름과 긴 제목은 자동으로 고쳐진다
- 그림 주의가 남으면 막대가 많은 그림은 가로 막대(`hbar`)로, 분류 기준 2개는 색 농도 그림(`heatmap`)으로 바꾼다
- 변수 주의: 참고 자료나 변수 찾기 결과에서 정의를 확인하지 않은 변수를 썼다는 뜻이다. `ssda.var_info(변수명)`으로 뜻을 확인하고 「유의 사항」에 적는다
- 없는 변수를 쓰면 실행되지 않고 비슷한 이름이 함께 돌아온다. 그 이름을 그대로 쓰지 말고 `ssda.var_info()`로 뜻을 확인한 뒤 쓴다

## 수치 대조와 보고 원칙

- 「결과」에 적은 수치는 실행 결과의 값과 자동으로 대조된다. 실행 결과에 없는 수치가 있으면 다시 작성하라는 요청이 온다
- 인정되는 수치: 실행 결과의 값, 만 명·조원 단위로 바꾼 값, 응답이 인용한 두 값의 차이
- 「결과」에는 질문에 대한 답을 먼저 적는다. 수치를 어림하거나 기억에 의존해 적지 않는다
- 「유의 사항」에는 적용한 가정, 분모, 기준 시점, 억제 칸 수, 확인하지 못한 사항을 적는다. 확인하지 않은 내용을 확인한 것처럼 쓰지 않는다
