# 자료 규약

## 자료의 단위와 가중치

- 자료는 개인 단위이며 한 행이 한 사람이다. 가구는 hid 로 묶이고 가구주는 head == 1 이다
- 개인 가중치 indwgt 의 합은 주민등록 인구, 가구 가중치 hhwgt 의 합(가구주 행)은 일반가구 수이다
- 분석 함수가 가중치를 자동으로 적용하므로 가중치 변수를 직접 쓰지 않는다
- 기준 시점: 인구·가구 2022. 11. 1., 급여는 2022년 연간(_yn1, _dur, _amt)과 12월(_yn2, _type), 사회보험 2022. 12. 31.

## 변수 이름의 접미어

| 접미어 | 뜻 |
|---|---|
| _yn1 | 연간 수급·가입 여부(해당하면 1) |
| _yn2 | 12월 기준 수급·가입 여부 |
| _yn | 여부(해당하면 1) |
| _dur | 연간 수급·가입 개월 수 또는 일수 |
| _amt | 연간 금액(원) |
| _type | 유형 코드(코드값은 var_info 로 확인) |

## 자료의 성격

- 개발·시험에는 코드북과 같은 변수 구조의 가상데이터(대역 자료)를 쓴다. 가상데이터의 수치는 실제 현황이 아니다
- 폐쇄망에서는 같은 코드가 원자료에 적용된다. 변수명·코드값은 같다
