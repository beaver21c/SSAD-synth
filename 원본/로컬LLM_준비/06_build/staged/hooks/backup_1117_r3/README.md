## 3. 설계 요지

- **모형은 분석 자료를 읽지 않음.** 모형에 전달되는 것은 질문, 참고 자료(변수 카드 등), 집계 결과의 표준 출력뿐임. 자료는 분석 함수가 별도 프로세스에서 읽어 집계함
- **통제는 코드 수준에서 강제함.** 분석 함수는 집계 결과만 돌려주고, 최소 관측 수·보충 억제·분류 기준 수 제한·유효숫자 반올림을 함수 안에서 적용함. 모형이 쓴 코드는 실행 전 점검을 통과해야 실행됨
- **모형별 도구 호출 형식에 의존하지 않음.** 모형의 동작은 파이썬 코드 블록 1개 작성으로 한정하고, 실행 결과는 「[실행 결과]」 문단으로 돌려줌. OpenAI 호환 주소를 제공하는 추론 서버이면 모형을 바꿔도 조립기를 고칠 필요가 없음
- **확인 절차는 하네스가 수행함.** 실행할 때마다 산출 결과와 그림을 자동으로 점검해 「[검증 결과]」로 모형에 돌려주고, 응답의 수치를 실행 결과와 대조하며, 「검증 요약」을 하네스가 만들어 응답 뒤에 붙임. 모형에는 검증 결과를 읽고 대처하는 일만 맡김
- **제도 용어는 사전으로 풀이하고 모호하면 되묻게 함.** 질문에 나온 제도명·약어를 사전에서 찾아 정식 명칭·구성 급여·변수를 참고 자료로 붙이고, 「국기초」「본인부담금」처럼 여러 내역을 묶는 말에 내역이 없으면 되묻거나 기본 해석을 가정으로 밝히게 함
- **보강은 단계적으로 함.** 프롬프트·검색만으로 평가 → 유사 예시 삽입 → 미세조정의 순서로, 평가 기준에 미달할 때만 다음 단계로 넘어감
