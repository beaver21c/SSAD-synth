# 분석 지원 도구 이용 안내

작성 기준일 2026-11-13 · 대상: 분석센터에서 도구를 쓰는 이용자(구축 후 배포용 초안)

## 1. 이 도구가 하는 일

- 질문을 분석 코드로 옮겨 실행하고, 집계 결과와 그림을 설명함
- 개인 단위 자료를 보여 주지 않음. 모든 결과는 최소 관측 수 등 출력 통제를 거친 집계값임
- 결과마다 「검증 요약」이 붙음. 도구가 자동으로 점검한 내용과 점검하지 못한 내용을 구분해 보여 줌

## 2. 질문하는 법

질문에 네 가지를 적으면 가정 없이 처리됨.

| 항목 | 예 |
|---|---|
| 대상 집단 | 65세 이상, 18~64세 여성, 1인 가구, 소득 1분위 |
| 지표 | 기초연금 수급률, 평균 급여액, 중위값, 구성비, 빈곤율 |
| 분류 기준 | 시도별, 연령대별, 성별, 가구원수별, 소득 5분위별 |
| 산출 형태 | 표, 막대그래프, 선 그래프, 시도 지도, 색 농도 그림, 파일 저장 |

- 예: 「65세 이상 기초연금 수급률을 시도별로 산출해 지도로 그려 줘」
- 대상을 적지 않으면 제도의 대상 집단을 분모로 두고 그 사실을 「분석 계획」의 가정에 적음
- 질문이 여러 뜻으로 읽히면 계산하지 않고 「확인 필요」로 되물음
- 이어서 물을 수 있음: 「소득 1분위만 대상으로 다시」, 「성별로도 나눠 줘」, 「방금 표를 그림으로」

## 2-1. 제도 이름과 약어

- 제도의 정식 명칭, 약어, 통칭을 그대로 써도 됨(국기초, 기초수급, 건보, EITC, 국취제, 두루누리 등). 도구가 제도 용어 사전으로 풀이해 해당 변수를 찾음
- 여러 급여나 내역을 묶어 부르는 말은 내역을 함께 적어야 함. 적지 않으면 도구가 「확인 필요」로 되물음

| 묶어 부르는 말 | 함께 적을 내역 |
|---|---|
| 국기초, 기초생활수급자 | 생계·의료·주거·교육급여 중 어느 급여인지, 하나라도 받는 사람 기준인지 |
| 본인부담금 | 외래인지 입원인지, 둘을 합한 금액인지, 요양기관 종별로 나눌지 |
| 진료비, 의료비 | 요양급여비용 총액인지 본인부담금인지 공단부담금인지 |
| 보험료 | 건강보험료, 장기요양보험료, 국민연금 보험료, 고용보험료, 사회보험료 합계 |
| 연금 | 기초연금, 국민연금, 직역연금, 장애인연금 |
| 국민연금 | 가입자 기준인지 수급자 기준인지 |
| 노인일자리, 산정특례, 긴급복지, 두루누리 | 유형·질환군·지원 종류, 하나라도 해당하는 사람 기준인지 |
| 저소득층, 취약계층 | 상대 빈곤층, 소득 1분위, 기초생활보장 수급자 중 무엇으로 정의할지 |

- 실업급여(구직급여), 주거급여(임차급여), 장기요양(수급 여부)처럼 기본 해석이 있는 말은 그 해석으로 산출하고 「분석 계획」의 가정과 검증 요약의 「용어」 줄에 표시함
- 부모급여, 비급여 진료비, 차상위계층 여부처럼 자료(2022년 기준)에 없는 항목은 없다는 사실과 대신 볼 수 있는 변수를 알려 줌

## 3. 응답 읽는 법

| 구획 | 내용 | 확인할 점 |
|---|---|---|
| 분석 계획 | 대상, 지표, 분류, 산출, 가정 | 대상과 가정이 의도와 같은지 |
| 코드 | 실행된 분석 코드 | 조건식(`where`)이 질문의 대상과 같은지 |
| 결과 | 질문에 대한 답과 수치 | 수치는 실행 결과의 값임 |
| 유의 사항 | 분모, 기준 시점, 억제, 한계 | 연간 기준인지 12월 기준인지, 억제 칸 수 |
| 검증 요약 | 도구가 자동으로 점검한 내역 | 아래 4절 |

## 4. 검증 요약 읽는 법

```
검증 요약(자동 점검)
- 실행: 코드 2회 실행
- 변수: 사용 변수 2개 모두 정의를 확인한 변수임
- 산출: 경고 없음 · 억제 0/17칸 · 분류하지 않은 전체 값 67.5%
- 그림: 1개 저장, 이상 없음
- 수치 대조: 「결과」의 수치 5개가 실행 결과와 일치
- 자동 점검 범위 밖: 지표 정의의 적절성, 해석의 타당성
```

| 줄 | 뜻 | 조치가 필요한 경우 |
|---|---|---|
| 실행 | 코드를 몇 번 실행했고 몇 번 고쳤는지 | 「차단」이 있으면 통제에 어긋나는 코드가 쓰였다가 막힌 것임 |
| 변수 | 쓰인 변수의 정의를 확인했는지 | 「정의 확인 없이 사용됨」이면 그 변수의 뜻을 직접 확인 |
| 산출 | 분모·분류 누락·억제 등의 점검 결과 | 「경고」가 남아 있으면 결과를 그대로 쓰지 않음 |
| 용어 | 묶어 부르는 말을 어느 변수로 해석했는지 | 「확인 필요」가 붙어 있으면 그 해석이 의도와 같은지 확인하고, 다르면 내역을 적어 다시 질문 |
| 그림 | 제목, 글자 겹침·잘림 점검 | 「주의」가 있으면 그림을 열어 확인 |
| 수치 대조 | 응답의 수치가 실행 결과에 있는 값인지 | 「확인 필요」이면 응답의 수치 대신 실행 결과의 표를 볼 것 |
| 자동 점검 범위 밖 | 도구가 점검하지 않는 사항 | 항상 이용자가 판단 |

## 5. 이용자가 직접 확인할 사항

자동 점검은 다음을 확인하지 않음.

- 지표의 정의가 분석 목적에 맞는지(예: 연간 수급 여부와 12월 기준 수급 여부 중 어느 것이 맞는지)
- 「수급자 가운데」「이용자의」처럼 제도로 정해지는 대상이 코드의 조건식에 들어갔는지
- 결과의 해석과 정책적 의미
- 그림의 종류가 내용에 맞는지

## 6. 응하지 않는 요청

- 개인 단위 행의 조회·출력·저장, 식별자 사용, 최솟값·최댓값이나 명단
- 억제 기준의 변경·해제, 억제 칸의 역산
- 자료 파일과 시스템에 대한 직접 접근, 외부 전송
- 대신 집계로 바꾼 대안을 제시함

## 7. 결과의 반출

- 표는 「저장해 줘」로 반출 신청 폴더에 저장됨(산출 조건 기록 포함). 그림은 그릴 때 저장됨
- 반출은 분석센터의 반출 심사를 거침. 질문, 코드, 검증 내역이 기록으로 남음
